# ERAI usable experimental build 81

这是本地离线实验版，不是正式发布版，也不包含智能护卫功能。

## 使用

1. 双击 `Configure-ERAI.cmd`。
2. 输入大盾兵数量 `1-5`，再输入孤狼数量 `1-3`。
3. 配置器只在本目录生成或复用参数包，并写入 `selection.json`。
4. 确认后双击 `Launch-ERAI.cmd`。它会重新核验选择、包哈希、Profile、游戏版本、进程状态、`start_online=false` 和 `natives=[]`，随后由用户手动启动当前选定的 C 环境 me3 配置。
5. 游戏内使用原生骨灰道具选择大盾兵或孤狼。两种骨灰不同时在场。

PowerShell 7 使用已核实的完整路径，不依赖系统 PATH，也不修改执行策略。

## 已验证范围

- 大盾兵 1-5：分别通过既有游戏验收。
- 孤狼 1-3：分别通过既有游戏验收。
- 同一 4+2 参数包：大盾兵4只、遣返后孤狼2只，游戏验收通过。
- 81号离线入口：4+2、2+3 已复用并核验；3+1 已在81目录独立生成并完成离线回读/门禁核验，但未进行游戏验收。
- 其它组合：只能视为离线生成或待验收，不得视为 GAME PASS。

## 停用与回滚

关闭游戏后，不再双击 `Launch-ERAI.cmd`，改用原版/既有 me3 启动入口即可。81号不覆盖游戏目录、原版 regulation.bin、全局 me3 配置、存档、DLL 或 native。删除或保留本目录都不会改变原有环境；已有74号、75号和历史资产未被覆盖。

## 限制

当前只提供数量与两种骨灰的独立参数组合。没有混合队伍、动态玩家保护、成员级目标控制、旧ERAI DLL/native 或运行时内存写入。
