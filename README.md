# ERAI Public Handoff

This branch contains a sanitized project handoff. It excludes personal videos, saved games, game archives, regulation binaries, LuaBND/DCX binaries, DLLs, caches, logs containing local identifiers, and proprietary game resources.

The original working assets remain on the original machine. Hashes and historical evidence are preserved in the reports, but absolute local paths have been redacted.

Start with README.md, then read reports/81-, reports/75-, reports/70-, reports/73-, reports/89- and reports/90-.

Current status: usable offline experimental build complete; intelligent proactive guard behavior not implemented and no verified member-level runtime control contract exists.
